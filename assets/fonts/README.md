# 字体来源

Google Sans 与 Google Sans Code 于 2026-11-11 从 Google Fonts 官方仓库取得，分别用于比例界面文字和等宽诊断文字。中文回退到 Noto Sans SC。字体随应用打包，运行时不连接字体服务。

- [Google Sans](https://github.com/google/fonts/tree/main/ofl/googlesans)：`GoogleSans[GRAD,opsz,wght].ttf`，本地文件 `googlesans.ttf`。
- [Google Sans Code](https://github.com/google/fonts/tree/main/ofl/googlesanscode)：`GoogleSansCode[wght].ttf`，本地文件 `googlesanscode.ttf`。

原始 OFL 许可保存在对应的 `*-OFL.txt` 文件，应用“第三方软件许可”可查看。保留原有 Roboto Flex 来源文件供历史构建参考，当前应用不再打包该字体。
