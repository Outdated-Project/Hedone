## 此前 Windows 场景

环境：Windows 10 Pro for Workstations 19045，Intel Core i7-11850H，Flutter 3.47.9，Profile 模式。测试入口为 `integration_test/rendering_profile_test.dart`。

两组使用相同界面、字体、解码策略和本机 HTTP 测试图片。基线临时恢复上一轮导航的 AnimatedBuilder / Opacity / FractionalTranslation，并保留已访问的全部五页；当前组使用 Flow 绘制阶段变换、空间弹簧与最多两页保活。测试后已恢复当前实现。不是上一版本完整安装包的对照，也没有视频解码或真实 CDN 延迟。

每组 48 条测试记录、20 次导航和 4 次滚动。每次滚动前回到相同位置，避免累计滚动距离改变图片工作集。首次未统一滚动位置的探索结果留在 `build/qa`，不用于下表。每组一次采样，没有置信区间。

## 固定侧栏与刷新率预算复测

[导航适配复测](navigation-responsive.json) 使用固定展开侧栏、胶囊导航实现和终态绘制快捷路径。Windows Profile 收集 423 帧，系统报告 60 Hz，build p50/p90/p99 为 0.567/2.356/6.839 ms，raster 为 2.337/3.620/9.416 ms；1 帧超出当前 16.67 ms 预算。采样 RSS 峰值 236.64 MiB。

本次侧栏宽度与可见图片数量已变化，不作为上述两组的严格性能对照。没有测得 90/120/165 Hz 的设备数据；特别是 raster p99 大于 165 Hz 对应的 6.06 ms，不能据此声称稳定 165 FPS。固定频率的 Widget 测试验证的是动画不依赖 16 ms 步长、不增加场景构建和布局，不是硬件吞吐测试。
