# 猜你喜欢

RecommendationProfile 维护与计算本地兴趣，RecommendationFeed 获取真实候选并处理分页。页面只负责展示，不持有算法或网络协议细节。

没有行为时对接口返回的候选随机洗牌。随机范围是可获取的候选集，不声称能够均匀抽样整个上游视频库。

## 信号与权重

观看至少五秒才进入画像；同一视频更新一条记录，不让每十五秒的进度保存变成重复投票。参与度在 0.15 到 1 之间，按两分钟进度封顶。观看信号半衰期十四天，搜索半衰期七天。标题和标签抽取英文词与中文双字片段，不运行模型、不引入分词词库。

观看和搜索分别归一化后按 65% / 35% 合成；只有一种来源时使用该来源。归一化结果再乘以该来源最强事件的衰减后强度，防止归一化抵消时间衰减，也避免一次短暂观看被放大为完整兴趣。运行中与恢复时均忽略九十天前的信号。切换到同一作品的新一集不会用较短进度覆盖既有参与度。重复搜索同一词只更新时间。基础分由兴趣匹配 80%、有限范围的上游评分 5%、随机扰动 15% 组成；最近看过的视频受到时间衰减惩罚。每五个位置安排一个探索位置，其余位置对与前四项高度相似的内容扣分，避免同题材挤满一屏。

这些权重是可解释的初始策略，未经过用户群 A/B 实验。播放进度作为参与信号，拖动进度会影响参与度；不把进度等同于精确观看时长。

## 候选与预算

每页读取真实 feed。第一页额外使用一个最近搜索词，或近期观看标签，查询当前线路；该可选请求最多等待两秒，失败或超时后使用正常 feed，不再让慢搜索拖住整页。超时不表示底层请求已取消，网络层原有时限仍生效。行为画像整体不上传，但用于召回的单个关键词会发送给当前线路。

分页区分上游空页和去重后的空页：上游没有条目即结束；已展示条目被过滤后仍保留上游的继续标记，用户可以继续加载后续新内容，不再提前显示全部加载完毕。

画像最多一百个视频和四十个搜索词；恢复时丢弃未来时间、超过九十天的记录和无效数值。单轮评分最多九十六个候选，特征数量有界。排序最坏开销 O(n²)，n 上限九十六，相似度仅对最近四项计算。Set 按视频 ID 去重，单次浏览会话约一千二百个结果后停止，刷新建立新会话。

请求以 generation 隔离；过时刷新不能写入当前去重集合。已展示页面不会因新观看事件自动跳位，下次刷新才重新计算。偏好与收藏、历史按来源存储，通过写队列保存；切换线路不混用画像。

“重置推荐偏好”恢复随机探索；清空观看历史也删除推荐信号。搜索词和偏好属于本地明文偏好数据，不是加密保险箱。
